# JP-s-Macropad

This is my first hardware project, yayyy, anyways I have made a simple 6 key macropad which I will be using it for CAD as love to do CAD and I have used its simple
shortcuts in this macropad. I have also added a rotary encoder and an OLED Screen. 

# Schematic & PCB

This was my first time making a schematic but it was fairly quick to make. It was because I saw tons of amazing examples on Stardance and took inspiration from many of them which made the process super simple.
